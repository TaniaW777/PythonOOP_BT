\## Description

This program is an innovative meal budgeting tool designed specifically for university students. Unlike basic calculators, our application includes snack budget tracking, financial insights showing spending patterns, and calculates long-term semester savings from discount cards. Students receive personalized daily spending recommendations and percentage breakdowns to help them make informed financial decisions about their food budget throughout the academic year.



\## Original Features

\- Integrated snack and beverage budget tracking

\- Financial insights with percentage analysis

\- Daily spending averages for practical budgeting

\- Semester-long savings calculations

\- User-friendly interface with helpful tips
